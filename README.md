# Calculador de cantidad de combustible en los tanques del corralón Nº3

## Se calcula el volumen de líquido (combustible) en base a la altura dentro del tanque recostado. Al ser una medida no lineal, 5 centímetros desde la base dan una medida diferente a, por ejemplo, 5cm entre 60cm y 65cm.
